# 荣誉与证书目录 (Certificates)

本目录用于存放学术成绩单、语言水平证书、专业技术认证以及各项竞赛奖项。

## 📂 证书分类
* **[学术荣誉](./academic)** - 毕业证书、学期优秀学生荣誉称号。
  * [第一学期优秀学生称号 (Honorable Student of Trimester - Term 1)](./academic/HonorableStudentOfTrimester_term1.pdf) 🏅
* **[语言水平](./language)** - 雅思 (IELTS)、托福 (TOEFL) 或其他英语技能水平认证。
  * [英语技能水平证书 (English Skills Certificate)](./language/English_Skills.pdf) 🗣️
* **[技术认证](./technical)** - 编程、集成电路 (IC) 设计、FPGA 开发或其他硬件相关的技术认证。
* **[竞赛奖项](./competition)** - 黑客马拉松 (Hackathon)、学科竞赛及各类工程设计奖项。
