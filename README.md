# Academic Portfolio Repository

This repository hosts an academic portfolio for a Physics undergraduate. Use the directories below to store CVs, certificates, scholarships, coursework reports, research projects, extracurricular activities, scripts, and documentation.

## Navigation
- [`cv`](./cv) – Curriculum Vitae files.
- [`certificates`](./certificates) – Academic, language, technical, competition, volunteer, and other certificates.
- [`scholarships`](./scholarships) – Scholarship applications and awards.
- [`coursework`](./coursework) – Course syllabi, assignments, and reports.
- [`research`](./research) – Research project proposals, data, analysis, and manuscripts.
- [`extracurricular`](./extracurricular) – Events, clubs, and volunteering.
- [`scripts`](./scripts) – Helper scripts (e.g., CV generation, static site build).
- [`docs`](./docs) – Guidelines and style guide.

Feel free to add content to each sub‑folder following the README instructions inside them.
